Лабораторная работа №1 «Искусственная жизнь».

Программа моделирует искусственную экосистему, содержащую три вида логических агентов: растения, травоядные и хищники.

Основные возможности:

Двумерная клеточная среда.

Поиск пищи, перемещение и размножение агентов.

Передача энергии между трофическими уровнями.

Настройка параметров симуляции.

Графическое отображение экосистемы на Java Swing.

Построение графика динамики численности популяций.

Технологии: Java 21, Swing, Eclipse.

В ходе тестирования был получен запуск продолжительностью 10 000 шагов без исчезновения какого-либо вида.

Исходный код находится в папке src, UML-диаграммы — в папке uml.

Запуск: открыть проект в Eclipse и выполнить Main.java как Java Application.
